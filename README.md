# Project Title

## Description
A React application with secure authentication.

## Technology Stack
- Node.js 20
- Express.js
- PostgreSQL 15
- React 18
- Docker
- JWT
- bcrypt

## Installation
- Clone the repository
- Install dependencies using `npm install` in both `backend` and `frontend` folders.

## Usage
- Start the backend and frontend applications using `bash run.sh` or `run.bat` on Windows.

## Project Structure
- `frontend`: React frontend code.
- `backend`: Express backend code.
- `tests`: Unit and integration tests.
- `docker-compose.yml`: Docker orchestration file.

## Configuration
Ensure that your environment variables are set in the `.env` files.
